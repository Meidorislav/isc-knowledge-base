# isc-knowledge-base

**[EN](README.md) | [RU](README.ru.md)**

> Гибридный RAG-поиск по корпоративной базе знаний: локальная LLM, антигаллюцинационный контур, онбординг и аналитика пробелов.

Дипломный проект (ВКР): «Разработка платформы интеллектуального поиска и генерации ответов на основе Retrieval-Augmented Generation с антигаллюцинационным контуром для предприятия ООО «ИСЦ»».

## Что делает система

- **Гибридный RAG-поиск** — сотрудник задаёт вопрос обычными словами; система ищет по документам гибридно (BM25 + векторный поиск), реранжирует кандидатов и через локальную LLM формулирует короткий ответ со ссылкой на источник. Строго по документам компании — если ответа нет, честно говорит «не знаю».
- **Онбординг** — граф зависимостей знаний (git → код → SQL KB → бизнес-процессы) → персональный план адаптации новичку, который сам обновляется при изменении вики.
- **Аналитика пробелов** — фиксирует вопросы без найденного ответа, чтобы ответственные за базу знали, что дописать.
- **Авторизация** — интеграция с существующим auth-сервисом компании (SSO); точная схема уточняется, на время разработки — мок-пользователь.

Всё работает **локально**, в инфраструктуре компании — вопросы сотрудников и содержимое регламентов не уходят во внешние API.

## Стек

| Слой | Технология |
|---|---|
| Backend | Python / FastAPI (один процесс: поиск, RAG, онбординг, аналитика) |
| Хранилище | PostgreSQL + pgvector |
| Полнотекстовый поиск | BM25 через ParadeDB `pg_search` |
| LLM | Ollama (Qwen2.5 / Llama 3.1, квантованные) |
| Эмбеддинги | bge-m3 (через Ollama) |
| Реранкер | bge-reranker (cross-encoder) |
| Frontend | TypeScript + React |
| CI/CD | GitHub Actions |

## Разработка

```bash
docker compose up -d db          # Postgres + pgvector + pg_search
cd backend && cp .env.example .env && uv sync
uv run alembic upgrade head
uv run uvicorn app.main:app --reload
```
